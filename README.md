# Wetware

Research-based cognitive training games with a cyberpunk frame. Play it at
https://raborn-decision-sciences.github.io/wetware/ (works offline once opened; installable).

Everything you do stays in your browser: nothing is sent anywhere. Export your data from
System → Data.

Release 0.1.0 (source 9b0b8a6). The method notes are in `docs/`. All rights reserved; see LICENSE.
